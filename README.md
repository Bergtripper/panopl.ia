# PANOPL.IA

**DOTZERO capability atlas for artificial intelligence.**

PANOPL.IA asks a different question: not *which AI is best?*, but *which combination of capabilities does this task require?*

The application maps five connected layers:

- **Capabilities** — the task primitives.
- **Arsenal** — tools described as capability profiles.
- **Recipes** — replaceable multi-tool workflows.
- **Tests** — repeatable protocols before rankings.
- **Time** — when capabilities become practically useful.

## Foundation

PANOPL.IA consumes DOTZERO Foundation as its single source of truth: semantic color tokens, typography switch, architectural grid, light/dark modes, `. / 0 / </>` graphic syntax, canonical `.DOTZERO` logotype and scroll-state sign. The initial consumer layer is pinned to `Bergtripper/dotzero@fe86791`.

### Data note

The initial tool profiles are deliberately marked **provisional editorial profiles**. They are interface seed data, not scientific benchmarks. The Test Lab is designed to replace subjective profiles over time with documented observations.
